# ILLUMINATE Ticket & QR Scanner Platform

Production-ready QR verification, check-in, and attendance management system for the **ILLUMINATE 2026** offline entrepreneurship workshop by **KMCT College of Engineering** in association with **E-Cell, IIT Bombay**.

## Features
- 🚀 **High-Speed Camera Scanner**: Real-time continuous QR code scanning with audio-haptic feedback.
- 📱 **Offline-Ready Client Engine**: Complete local attendance database storing registered participants with Instant check-in/duplicate rejection.
- 🎫 **Digital Pass & Verification**: Beautiful participant pass view, verification modal, and one-click manual check-in.
- 📊 **Real-time Live Attendance Dashboard**: Checked-in counters, active cohort status, and live log stream.
- 📥 **CSV Attendance Export**: Export formatted attendance logs directly to CSV for coordinator reporting.

## Deployment on Vercel
This repository is pre-configured with root `vercel.json` for seamless zero-config deployment on [Vercel](https://vercel.com).
